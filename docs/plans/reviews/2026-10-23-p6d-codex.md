## Blockers

- [cmd/keel/initplan.go:44](cmd/keel/initplan.go:44), [cmd/keel/scaffold.go:124](cmd/keel/scaffold.go:124), [cmd/keel/initplan.go:134](cmd/keel/initplan.go:134) — `keel init` follows repository symlinks and cannot faithfully roll them back.  
  Failure scenario: a tracked file is a symlink to a regular file outside the repository. `os.Stat` accepts it and `os.WriteFile` rewrites the external target. Deleted files are restored as regular `0600` files, losing symlink identity and original mode. A `commitAll` failure returns directly at [cmd/keel/init.go:100](cmd/keel/init.go:100), leaving that degraded rollback in place.  
  Fix: use `Lstat`, reject symlinks and non-regular files from all mutation targets, prevent symlink traversal when opening files, and journal original mode/type/link target. Ensure `commitAll` failures receive the same complete rollback guarantee as later failures.

- [internal/app/tenancy_off.go:35](internal/app/tenancy_off.go:35), [internal/app/commands.go:307](internal/app/commands.go:307), [internal/app/modules.go:90](internal/app/modules.go:90) — removing tenancy leaves the operator capability usable.  
  Failure scenario: a `notenancy` build still accepts `APP_DATABASE_OPERATOR_URL`; `db.Open` creates `*db.OperatorAccess`, and every module command receives it. A custom module can therefore execute through a bypass-role pool despite the tenancy/operator realm being removed. This also violates the comment that the capability is handed only to operator-realm wiring.  
  Fix: make the off twin reject operator URL/realm configuration, do not open an operator pool without tenancy, and remove `*db.OperatorAccess` from the generic module `Opener`. Provide a separate, explicitly operator-scoped command interface.

- [internal/kit/otelx/otelx.go:116](internal/kit/otelx/otelx.go:116), [internal/kit/otelx/otelx.go:129](internal/kit/otelx/otelx.go:129) — public clients can override the configured trace sampling rate.  
  Failure scenario: `ParentBased(TraceIDRatioBased(...))` trusts the sampled bit of an incoming `traceparent`. Any public client can continuously send sampled remote parents and force request spans to be exported, bypassing the configured ratio and increasing telemetry cost.  
  Fix: treat inbound HTTP as a public endpoint using `otelhttp.WithPublicEndpoint()`, or install a sampler/propagator that honors parents only from authenticated trusted upstreams.

- [internal/kit/migrate/validate.go:499](internal/kit/migrate/validate.go:499), [internal/kit/migrate/policy.go:170](internal/kit/migrate/policy.go:170) — procedural migrations bypass the RLS validator.  
  Failure scenario: dollar-quoted bodies are replaced with `$$`, so a migration such as a `DO` block dynamically executing `ALTER TABLE … DISABLE ROW LEVEL SECURITY` is invisible to `tenantDDL`. The migration commits while the currently running release continues serving against an unprotected table; the next startup check is too late.  
  Fix: reject procedural/dynamic SQL capable of schema or policy changes, or parse and validate those bodies. Also run catalogue validation inside the migration transaction before commit.

- [internal/kit/tenancy/catalogue.go:72](internal/kit/tenancy/catalogue.go:72), [internal/kit/tenancy/catalogue.go:127](internal/kit/tenancy/catalogue.go:127), [internal/kit/tenancy/catalogue.go:329](internal/kit/tenancy/catalogue.go:329) — security-definer exceptions are matched only by function name.

  Fix: identify functions by schema-qualified `regprocedure` signature and validate owner, pinned `search_path`, ACLs, and expected definition or fingerprint.

## Fix pass (init and tooling)
- **Blocker 1 (symlinks and rollback)** fixed (`cmd/keel/scaffold.go`, `initplan.go`, `init.go`).
  - The plan lists files with `Lstat`. Symlinks and other irregular entries are never changed or deleted: `replace`, `remove` (a directory holding one included) and the commit-time write and unlink all refuse them. A write whose parent directory is a symlink is refused too. `exists` uses `Lstat`, so a dangling link counts as existing.
  - The undo journal records each deleted file's mode and restores it.
  - A `commitAll` failure and an interrupt now run the full `git reset --hard` / `git clean -fd` rollback on a detached context.
  - Tests: `TestPlanTree_RefusesSymlinks` (an outside file behind a link stays untouched, and nothing is written through a linked directory), `TestCommitAll_UndoKeepsModes`, and `TestApplyInit_RollsBack` (injected mid-commit failure, and cancellation).
- **Nit (self-check)** fixed (`cmd/keel/initplan.go`, `staleNames`). After the rewrites, the plan fails when:
  - a non-Go text file outside `docs/`, `internal/kit/` and `.gitignore` still holds text a name replacement would change;
  - under `--env-prefix`, any file outside `internal/kit/` and keel's own test fixtures still names an `APP_` setting other than `APP_TEST_*` or the bare prefix.

  The first check found that `.github/workflows/deploy-test.yml`'s `-t app:` was not covered; it now is. `TestInitPlan_StaleNames` covers the rule and its allowlist.
