## Blockers

- **internal/kit/files/inspect/pdf.go:143** — PDF streams are decoded only when the filter map contains the full `FlateDecode` name, and only one decoding pass is performed. Filter abbreviations such as `/Fl`, chained Flate filters, predictors in `DecodeParms`, indirect filters, and unknown non-image filters can hide JavaScript or embedded objects and be accepted. Fix: parse the ordered filter chain and parameters, or conservatively reject anything except one supported Flate filter without predictors; add bypass tests for abbreviations, chains, predictors, and indirect filters.

- **internal/kit/files/inspect/zip.go:290** — OOXML attribute lookup ignores XML namespaces. A relationship can place a safe prefixed `evil:Type` or `evil:TargetMode` before the real unqualified malicious attribute, causing external templates or macro relationships to pass inspection while Office honors the real attribute. Fix: require the expected element namespace and unqualified attributes (`Name.Space == ""`), rejecting ambiguous duplicates; add crafted macro and external-relationship tests.

- **internal/kit/files/service.go:151** — Re-encoded PNG/JPEG output is written through an unbounded counting writer. A compressed image below `Policy.MaxBytes` can be re-encoded into a much larger object, bypassing the upload cap and consuming excessive temporary and storage space. Fix: cap rewritten output at `MaxBytes+1`, return `ErrTooLarge`, and test a small input whose rewrite exceeds the policy.

- **internal/kit/files/inspect/inspect.go:151** — GIF and WebP are detected but have no inspection path. Enabling inspection rejects every such image; disabling it bypasses dimension and pixel checks, allowing decompression bombs. Fix: run `image.DecodeConfig` and enforce dimension/pixel budgets for GIF and WebP without rewriting them; add huge-header corpus cases.

## Should-fix

- **internal/kit/files/sweep.go:95** — The orphan check and storage deletion are not coordinated with `Service.Stage`. An object older than `MinAge` can gain a committed row after `knownKeys` returns but before `Delete`, leaving an attached row whose object was removed. Fix: introduce coordination between Stage and final orphan deletion, or enforce a durable upload claim/lifetime invariant; add a concurrent Stage-versus-Sweep test.

- **internal/kit/files/s3.go:39** — `S3Options.SSE` defaults to `false`, contrary to the documented “SSE on by default” contract. Direct callers that omit the field silently upload without server-side encryption. Fix: make disabling SSE explicit, such as `DisableSSE`, and default `PutObject` to AES-256.

- **internal/kit/files/s3.go:131** — Presigned S3 downloads set disposition and type but cannot provide the required `nosniff` and sandbox CSP headers. `Service.PublicURL` does not prevent active types such as PDFs from taking this path. Fix: serve untrusted/active public objects through `fileshttp`, or require a proxy/CDN that injects the security headers and enforce that configuration.

- **internal/kit/files/storage.go:118** — Local writes sync the file and destination directories after rename, but never sync the temporary source directory. This does not meet the specified crash-durability sequence for a cross-directory rename. Fix: sync `.tmp` before rename and sync both source and destination directories afterward.

- **internal/kit/paging/feed.go:267** — An upsert and tombstone with the same `(change_xid,id)` can straddle a page boundary. For example, deleting and recreating one ID in a Postgres transaction causes the tombstone to advance the token and the equal-position upsert to be excluded forever. Fix: collapse identical positions according to final row state, prohibit ID reuse, or add an operation sequence to the position; test with `limit=1`.

- **internal/kit/files/service.go:212** — `Attach` accepts `uuid.Nil` as the polymorphic owner ID, violating the zero-ID rule and creating an attachment that cannot reference a real owner. Fix: reject `uuid.Nil` before updating the row.

- **internal/kit/files/sign.go:48** — Signed-link parsing has no input bounds and does not require a positive TTL at generation. Oversized query values can allocate unnecessarily, while callers can accidentally create immediately expired links. Fix: require exact MAC encoding length, bound the expiry string, and validate positive, preferably capped, TTLs.

## Fix pass

Blockers:
- **PDF filters: fixed.** The scanner is rewritten to fail closed. It allows only the full-name FlateDecode (chains of Flate decoded in turn, PNG and TIFF predictors undone) and, on exact image XObjects only, one final DCT, JPX, CCITT or JBIG2 filter. Abbreviations, indirect `/Filter` or `/DecodeParms`, other filters and a predictor it cannot undo are refused. Corpus rows cover each case. See the Opus review's fix pass, item 1.
- **OOXML namespaces: fixed.** `Type`, `Target`, `TargetMode` and `ContentType` are read only unqualified. A namespaced or repeated one is refused, with a corpus row for a prefixed `TargetMode` before the real one.
- **Re-encode growth: fixed.** The re-encode writes through a writer capped at `Policy.MaxBytes`, and exceeding it is `ErrTooLarge`. Tested with a low-quality JPEG that grows on re-encode.
- **GIF and WebP: fixed.** GIF screen size and frame count come from a block walk, with frames times pixels held within the decoded-bytes budget. WebP uses `x/image/webp` DecodeConfig plus an ANMF frame count. Neither is re-encoded; both keep their metadata, which is documented. Corpus rows cover a clean file, a huge canvas and too many frames.

Should-fix:
- **Sweep versus Stage: fixed by design.** Put inserts a pending row in its own transaction before writing the object, so an object never lacks a row while being uploaded. Expiry takes rows with `FOR UPDATE SKIP LOCKED`, so a Stage holding the row is skipped. TestSweep_LeavesAFileBeingStaged covers this on both engines.
- **SSE default: fixed.** `S3Options.DisableSSE` replaces `SSE`, so the zero value encrypts. A test loads the config with defaults against a fake endpoint and sees `AES256`, and the contract checks HeadObject.
- **Presigned downloads: fixed.** Presigning is opt-in per policy (`Policy.Presign`, refused at construction if the storage cannot presign), and fileshttp.Public is the default. The limits are documented.
- **Temp directory sync: fixed.** Local.Put syncs `.tmp` and the destination chain after the rename.
- **Feed equal position: fixed.** The order is (position, id, tombstone before upsert), and the token carries the side. When a token ends on a tombstone, the row at the same position is still selected. TestFeed_RecreatedRowFollowsItsTombstoneAcrossPages pages with limit 1 on both engines.
- **Attach with uuid.Nil: fixed** (refused).
- **Signed-link bounds: fixed.** `expires` is at most 20 characters, the signature must be exactly 43, and the TTL must be positive and at most seven days on both sign and verify. Every key is compared.

Nits:
- The full Postgres and MySQL matrix was run with `keel test`.
- The P4 handoff and the wiring list are in the coordinator report.
