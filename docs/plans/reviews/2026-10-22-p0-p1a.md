# Review: P0 and first half of P1 (2026-10-22)

Scope: go.mod, tools/go.mod, .golangci.yml, Makefile, docker-compose.yml, .env.example, deploy/db/postgres-roles.sql, .github/workflows/ci.yml, cmd/app, cmd/keel, internal/app, internal/kit/{cli,config,logx,clock,ids,buildinfo,dates,money}. The concurrent httpx, health and server work is excluded.

Verdict: **fix-then-ship**. One blocker (log redaction bypass); the rest are should-fix items that later phases will build on.

## Verification (run by the reviewer, not taken from a report)
- `go run ./cmd/keel check` currently fails at `go mod tidy -diff`, because the concurrent agent is partway through go.mod (chi, x/sync). This is not a defect in this scope; rerun once that work lands.
- Scoped to the packages above: `golangci-lint fmt --diff` is clean, `golangci-lint run` reports 0 issues, `go vet` is clean, govulncheck finds no vulnerabilities, and `go test -race -count=1` passes in about 7 s wall time. `tools/` tidy is clean.
- The pinned action SHAs match their tags (checked with `git ls-remote`: checkout v7.0.1, setup-go v7.0.0).
- depguard rejects `import "unsafe"` (checked in a scratch copy).
- Defects marked "probe" below were reproduced with throwaway tests injected through `go test -overlay`. No repo file was touched.

## Findings

1. **blocker**, internal/kit/logx/logx.go:109-162. Redaction misses common key shapes. normalise inserts `_` before every capital, so all-caps keys and acronyms split into single letters. A probe showed all of these logged in clear: `PASSWORD`, `AccessTOKEN`, `APIKey`, `OTPCode`, and the canonical header form `X-Api-Key` (which normalises to `x__api__key`, so the bigram check sees empty words). PII and credential keys are also missing: `email`, `phone`, `pin`, `pwd`, `credentials`, `private_key`, `signing_key`, `session_id`, `recovery_code`, `jwt`, `bearer`, `dsn`, `database_url`, `mfa_keys`. Security.md section 7 names emails explicitly. Fix: lowercase first, split on any non-alphanumeric character and on lower-to-upper transitions only (a run of capitals stays one word), and drop empty words. Then match single words and joined bigrams, and extend the list. Add the keys above to TestRedaction.
2. **should-fix**, internal/app/config.go:8 (and docs/configuration.md:13). `APP_ENV` defaults to `local`, so a deploy that forgets the variable silently runs without the production profile. Fix: make `APP_ENV` required (.env.example already sets it), or at least refuse a non-loopback `HTTP.Addr` unless the env was set explicitly.
3. **should-fix**, internal/kit/config/secret.go. There is no mechanism yet for the section 1 rule "secret shorter than 32 bytes or still has its example value". Settle the API before P3 adds keys. Suggestion: a `config.Key` type (at least 32 bytes in prod), distinct from `Secret`, which covers DSNs and similar values. Have the `validate` walker refuse, in prod, any Key or Secret that matches the placeholder convention used in .env.example.
4. **should-fix**, internal/kit/config/config.go:50-63. When both `X` and `X_FILE` are set, the plain variable silently wins, so a rotated file secret can be shadowed by a stale env value. The file read is also unbounded (`/dev/zero` never returns). Fix: error when both are set; read through `io.LimitReader` (64 KiB) and refuse non-regular files.
5. **should-fix**, internal/kit/logx/logx.go:92-107. Context attributes are added inside any open group, so `logger.WithGroup("http")` buries `request_id` under `http`. logx_test.go:63 asserts that behaviour. Log queries need these keys at the top level. Fix: have contextHandler record its WithAttrs and WithGroup calls and apply the context attributes to the root handler before replaying them, or forbid groups on request loggers. Update the test.
6. **should-fix**, internal/kit/cli/cli.go:47-56. `signal.NotifyContext` keeps capturing signals until `stop()` runs, so a second Ctrl-C or SIGTERM during a hung shutdown does nothing. `serve` will inherit this. Fix: call `context.AfterFunc(ctx, stop)` inside SignalContext, so the first signal cancels and later ones get the default behaviour.
7. **should-fix**, docs/conventions/go.md:12. The documented form `type InvoiceID ids.ID[invoiceTag]` is a defined type, which drops every method. Probe: it marshals as `{"ID":[1,161,100,...]}` and loses Scan, Value and Schema. packages.md:36 and the tests use the alias form. Fix go.md to `type InvoiceID = ids.ID[invoiceTag]`.
8. **should-fix**, internal/kit/ids/ids.go:36-45 and 87. `Value()` writes the nil UUID for an id that was never set, and `Parse` accepts `00000000-...`. Fix: `Value` refuses zero (as `dates.Value` does), `Parse` rejects the nil UUID, and nullable columns use `*ID`.
9. **should-fix**, ids.go:38,42; dates.go:33,39; money.go:50. Parser errors embed the raw input, and Huma copies that message into the 422 body. Probe: `"message":"invalid value: invalid id: \"SECRETVALUE-not-uuid\" ..."`. Fix: drop `%q` of the input from these messages. For the httpx owner: Huma's `ErrorDetail.Value` also echoes input and must be stripped by the problem mapper (security section 5).
10. **should-fix**, internal/kit/dates/dates.go:13-17, 104-139. Without a `Schema` method, the spec documents a Date as a plain `string` with no `format: date` (probe). Exported fields let invalid dates through: `Date{2026,13,40}.Value()` returns `"2026-13-40"`, and `9999-12-31 + 1 day` yields an unparseable `10000-01-01` (probe). Fix: add a `Schema` method like the one in ids, and validate through `New` in `MarshalText` and `Value`.
11. **should-fix**, internal/kit/money/money.go:25-28, 57, 83. The zero `Amount{}` marshals to `{"amount":0,"currency":""}`, which its own UnmarshalJSON rejects (probe). Add and Allocate accept an empty or unknown currency. Fix: refuse an invalid currency on marshal (mirroring dates), and validate the receiver's currency in Add and Allocate.
12. **should-fix**, money.go:47-53. The exponent comes from bojanz CLDR data at runtime. If a dependency bump changes one currency's digits, every stored amount in that currency is silently rescaled. Today IQD=3, ISK=0 and CLF=4 match ISO 4217 (probe). Fix: a table test pinning the exponent of every currency the app accepts.
13. **should-fix**, deploy/db/postgres-roles.sql:1-12. The script sits under `deploy/` but silently falls back to well-known passwords. Fix: move it to `deploy/local/`, or turn it into an initdb `.sh` that reads passwords from env and fails when they are unset outside compose.
14. **should-fix**, postgres-roles.sql:24-27. The default privileges give both the app and operator roles UPDATE and DELETE on every table the owner creates, including `goose_db_version` and the future append-only `audit_log`. Fix: grant per table in migrations, or record now in database.md that P2 and P3 revoke on those tables, with a catalogue test.
15. **should-fix**, .github/workflows/ci.yml:22,43,57,92,109,125. `actions/checkout` persists the token in `.git/config`. Fix: `persist-credentials: false`.
16. **should-fix**, ci.yml:29-50 and Makefile:26-27. CI and `make vuln` bypass `keel`, so CI and local runs already differ (CI runs `go mod tidy` followed by `git status`, while keel runs `tidy -diff`). Plan P0 says everyone runs the same thing. Fix: add `keel tidy` and `keel vuln` subcommands and have every CI job call `go run ./cmd/keel <step>`.
17. **should-fix**, ci.yml:39 and .github/. govulncheck runs only on PRs, so advisories published against unchanged code are never seen, and there is no Dependabot or Renovate config (security section 8). The pinned SHAs will go stale. Fix: also run vuln on `schedule`, and add `.github/dependabot.yml` covering gomod at `/` and `/tools`, github-actions, and docker.
18. **should-fix**, Makefile:6-9. `include .env` plus a bare `export` pushes every .env value, secrets included, into every recipe, including `go test`. internal/app tests read the ambient env, so a developer's `.env` can fail them: for example, `APP_PROXY_EDGE=cloudflare-tunnel` without an address breaks TestConfigCheck_PrintsRedactedConfig. make also expands `$` inside values. Fix: export .env only for `dev` and `up`, and add `LoadConfigFrom(environ)` for tests.
19. **should-fix**, .gitignore:1. Only `.env` is ignored, so `.env.production` and similar files are committable. Fix: `.env*` plus `!.env.example`.
20. **should-fix**, .golangci.yml. AGENTS rules 1 and 9 have no mechanical guard: `time.Now()` passes lint (checked). Fix: forbidigo for `time.Now` outside kit/clock, for `os.Getenv` and `os.Environ` in internal/kit outside config, and for `fmt.Print*` outside cmd.
21. **nit**, money.go:67-73. `Sub(-1, MinInt64)` refuses a representable result (MaxInt64) (probe), and reports overflow instead of currency mismatch when b is MinInt64. Fix: a direct bounds check without Neg.
22. **nit**, money.go:165. The overflow error renders the whole decimal, up to 10k digits. Include only the currency. Also money.go:176,189 discard the exponent error with `_` and no comment; compute it once.
23. **nit**, money.go:26. D18 promises JavaScript safety up to 2^53, but `amount` accepts any int64. Add `minimum` and `maximum` tags of plus or minus 9007199254740991.
24. **nit**, internal/kit/config/parts.go:29,89-96,146-149. `http://` CORS origins are allowed in production. PublicURL accepts userinfo, path and query, and echoes the value in its error. The tunnel edge does not require Trusted, which contradicts security.md:14. Align the code or the doc.
25. **nit**, config.go:93-120. `validate` does not descend into pointers or slices of structs, so a future `[]Realm` part would skip Validate silently.
26. **nit**, config.go:17-19. `kit/config.Load` reads `os.Environ`, which contradicts hard rule 1. Move `Load` to internal/app (kit keeps `LoadFrom`) or amend the rule.
27. **nit**, logx.go:114. Values are not inspected: `slog.Any("req", struct{Password string})` logs the password. Say so in the logging rule in go.md. Exact-match `code` redaction will also hide problem codes in logs.
28. **nit**, clock.go:67 and dates.go:76. Passing a nil location panics. The plan's P1 text says "Wall and Business, each with a location", which disagrees with packages.md and the code. Fix the plan text.
29. **nit**, ci.yml:73-76. The DB matrix uses floating tags while compose pins exact versions. There is no `concurrency` cancel. `APP_TEST_ENGINE` and `APP_TEST_DATABASE_PORT` are read by nothing, and the roles script never runs in CI (P2 must add it). The P0 nilaway advisory step is absent.
30. **nit**, cli.go:93. Go's flag package stops at the first positional argument, so `queue:work a --once` silently treats `--once` as an argument. Refuse `-`-prefixed args after a positional. cmd/keel/steps.go:44 prints straight to os.Stdout, bypassing the `fs.Output()` contract.
31. **nit**, docker-compose.yml:22-36. MySQL runs as root only, with no owner/app split, so local MySQL does not match production.
32. **nit**, comments that restate code; delete them: cli/print.go:21,27; config/bytesize.go:22; clock/clock.go:34,57; ids/ids.go:89; money/money.go:24,170; Makefile:14 "(nilaway joins in a later phase)".
33. **nit**, cli_test.go:182-193. TestSignalContext_CancelsOnSIGTERM tests the standard library and sends a real SIGTERM to the test binary. Remove it.
34. **nit**, clock_test.go:16-23 (TestBusiness_DefaultsToRealTime tests `time.Now`), ids_test.go:30-38 (TestStable tests google/uuid), cmd/keel/steps_test.go:9-21 (restates the slice literal), dates_test.go:75-87 (trivial Before, After, Equal), and the level-filtering half of logx_test.go:132-142. Remove or trim them.

## Fix pass

`go run ./cmd/keel check` passes (tidy, format, lint, vet, govulncheck, `go test -race ./...`).

1. Fixed. logx splits keys on case changes (acronym runs), non-alphanumerics and letter-digit changes, matches words and adjacent pairs, trims a plural `s`. Table test covers the review's shapes and the non-matches. Changed: a trailing `code` is redacted only after a qualifier (otp, recovery, verification, mfa, sms, backup, reset, invite, ...), because "ends in code" would also hide `status_code`. Added `pwd`, `bearer`, `signing key`, `database url` from the review list. Not covered: `mfa_keys`.
2. Fixed. `APP_ENV` is `required,notEmpty`; `config.Load` is removed, `app.LoadConfig(environ)` and `app.Commands(environ)` take the environment, `cmd/app` passes `os.Environ()`, tests pass explicit slices. `make dev` defaults `APP_ENV=local`; keel has no command that runs the app, so it sets nothing.
3. Fixed. `config.RequireStrong(name, secret, prod)` (32 bytes, internal list of example values; .env.example has no secrets yet). Setting `X` and `X_FILE` together is an error; file reads are capped at 64 KiB and must be regular files. Not wired into any field yet: no Secret fields exist in the app config.
4. Fixed. contextHandler keeps the root handler plus recorded WithAttrs/WithGroup calls and adds context attributes before replaying them. Test asserts top level.
5. Fixed. First signal cancels, second exits 130. TestSignalContext removed; one unit test drives the escalation through a channel, no real signals.
6. Fixed. Zero id is NULL on `Value`, NULL scans to the zero id, error messages name the format only. `Parse` still accepts the nil UUID (the brief did not ask to reject it).
7. Fixed. dates implements `Schema` (format date), validates year 1..9999 and real dates in New, Parse, UnmarshalText and Scan; Value and MarshalText refuse invalid dates. Errors never carry the input. Huma test added.
8. Fixed. Zero `Amount` fails `MarshalJSON`; exponent table test for USD, EUR, JPY, KWD, BHD, MVR; `Sub` uses a direct bounds check. Add, Sub and Allocate refuse an empty or unknown currency.
9. Fixed. `postgres-roles.sql` has no defaults and raises a clear error for each missing psql variable (verified in a throwaway postgres:17 container). `deploy/db/local-init.sh` passes local-only passwords from compose. Default privileges grant SELECT, INSERT, UPDATE, DELETE; the script revokes `goose_db_version` and its sequence when they exist. Gap: default privileges run at table creation, so the revoke only bites if the script is re-run after the first migration (documented in database.md; P2's migrate step should do it, or goose should use a schema the app roles cannot reach). Role creation is now idempotent so the re-run works.
10. Fixed. `persist-credentials: false` everywhere; jobs call `keel tidy`, `keel lint`, `keel vuln`, `keel test` (new `tidy` and `vuln` commands, `lint` now includes format and vet, `check` is built from the same step lists); vuln runs on PR, push to main and nightly; concurrency cancels superseded PR runs; `.github/dependabot.yml` covers gomod (`/` and `/tools`), github-actions, docker and docker-compose, weekly, minor and patch grouped.
11. Fixed. Makefile no longer includes or exports `.env`; only `make dev` sources it, and compose reads it itself. `.gitignore` is `.env*` with `!.env.example`.
12. Fixed. forbidigo: `time.Now` everywhere except internal/kit/clock, `os.Getenv/LookupEnv/Environ` outside internal/kit/config and cmd, `fmt.Print*` outside cmd. Violations fixed: httpx AccessLog now times with `clock.Wall(ctx)`; the server test polls with a timer. tools/ is a separate module and is not linted.
